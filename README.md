# 推しグッズノート ♡

推しキャラごとにノートを作って、グッズを写真つきで記録できるWebアプリです。

## できること
- 推しごとのノート（名前・作品名・アイコン写真・推しカラー）
- グッズ登録：写真、グッズ名、個数、イベント、状態（所持／譲／求）、種類、入手日、金額、メモ
- イベント別の表示、状態での絞り込み、検索
- バックアップの書き出し・読み込み（JSONファイル）
- **▶ 動画タブ**
  - **お気に入り動画ノート**：YouTubeのURLを貼るだけで保存（タイトル自動入力）。お気に入りシーンの時間・タグ・メモつき、アプリ内で再生できます
  - **新着**：推しのYouTubeチャンネルを登録すると、最新動画が新しい順に並びます。♡ でワンタップ保存
- **ホームで新着がひと目でわかる**：アプリを開くと「🆕 推しの新着」に全推しの最新動画が並び、まだ見ていない動画に NEW、推しカードに「NEW 2」のような件数バッジがつきます
- **壁紙の着せかえ**：右上の 🖼 から、ホーム・推しノート・イベントごとに壁紙を設定できます
  - 柄（ドット／ストライプ／ギンガム／ハート／ほし／グラデ／むじ／みんなの推し色）× 推しカラーや好きな色
  - 自分の写真（白いベールの濃さ・ぼかしを調整）
  - イベントの壁紙は、グッズ一覧でそのイベントを選んだときに表示されます

## 新着を使うには（YouTube連携）
お気に入りノートは準備なしで使えます。新着の自動取得だけ、最初に1回だけ準備が必要です（無料・5分くらい）。
ホーム画面の「▶ YouTube連携」を開くと、3ステップの案内とページへのボタンが出てきます。
1. YouTubeの機能をオンにする（Googleのページで「有効にする」を押す）
2. 合言葉（APIキー）をつくってコピー
3. アプリに貼って「たしかめて保存」

合言葉は各端末のブラウザにだけ保存され、リポジトリやバックアップには入りません。

## データの保存先
データと写真は、開いた端末のブラウザ（IndexedDB）に保存されます。サーバーには送られません。
別の端末とは共有されないので、機種変更の前などにホーム画面の「💾 バックアップ」から書き出してください。

## 公開方法（GitHub Pages）
1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

`index.html` 1ファイルだけで動きます。
